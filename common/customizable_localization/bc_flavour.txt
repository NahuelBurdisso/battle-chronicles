# Battle Chronicles - prose fragments.
#
# THE ARMS ONLY COMPARE FLAGS. Every classification decision was made in
# bc_context_effects.txt, where it could be logged. Nothing here decides
# anything; it selects a sentence for a decision already recorded. If a
# fragment renders wrong, the marker in the log says which of the two it was.
#
# type = character ON EVERY DEFINITION, and invoked on a SAVED SCOPE, never on a
# variable-held character. Vanilla's Custom2 second argument is always a saved
# scope or ROOT.Char - a variable-held character has zero uses in vanilla or
# AGOT - so the mod does not use Custom2 at all.
#
# THE FALLBACK ARM IS LAST AND HAS NO TRIGGER. CK3 takes the first matching arm
# in order, so a trigger-less arm anywhere but last would swallow the ones below
# it. Every definition here ends in one.
#
# HOW MUCH THAT FALLBACK IS WORTH VARIES BY DEFINITION, and each one says so in
# its own header. It is load-bearing on the ground clauses, because
# bc_write_ground_effect removes the variable first and has two exits that never
# rewrite it. It is unreachable on bc_bond_clause, because bc_write_bond_effect
# writes on every path. Do not generalise either case to the other; check the
# writer.
#
# NESTED, NOT SIBLING, on the variable read. The bare `exists` row and the
# trigger_if are safe as siblings - only the READ has to be nested, which is
# what the trigger_if does. A `trigger_if` whose `limit` fails evaluates TRUE,
# so the bare `exists` beside it is the row that actually rejects.

# --- SPIKE. The only fragment until a run proves this shape renders. ---------
bc_banner_falls_ground = {
	type = character

	text = {
		localization_key = bc_frag_banner_falls_desert
		trigger = {
			exists = var:bc_battle_ground

# --- the bond, shared by all ten moments -------------------------------------
#
# SHARED AND NOT PER-MOMENT, unlike the per-moment ground clause above (one so
# far, and a spike). A clause about the foe reads the same after a banner falling
# as after a flank collapsing; a clause about the ground does not - a standard
# goes down IN the sand, a flank collapses AMONG the trees. The verb has to agree
# with the ground and does not have to agree with the foe. That is the whole
# reason this is one definition and the ground is ten.
#
# FIVE VALUES, MATCHING bc_write_bond_effect'S LADDER EXACTLY: nemesis, kin,
# countryman, heathen, stranger. `stranger` gets a real clause rather than
# sharing the fallback because it is a real answer - bc_context_effects.txt:201-206
# routes a LEADERLESS enemy side here on purpose, and its comment says why.
#
# THE ORDER OF THOSE FIVE IS NOT THE ORDER THE EVE USES, deliberately. The eve's
# desc chain runs nemesis, kin, heathen, countryman, stranger; the ladder in
# bc_write_bond_effect runs nemesis, kin, countryman, heathen, stranger. This
# clause renders whatever the LADDER decided, so a same-culture different-faith
# foe reads `countryman` in the toast and `heathen` in the eve, in the same
# battle. That is the documented intent - see the reciprocal notes at
# bc_context_effects.txt:136-146 and bc_eve_events.txt:60-66 - and this is now
# the third carrier of those five values and the first whose ordering reaches the
# player as prose. Do not "reconcile" the two.
#
# THIS CLAUSE READS THE BOND AND NOT THE CREED. bc_write_bond_effect also writes
# an orthogonal var:bc_battle_creed, which exists precisely because the ladder
# buries faith under nemesis/kin/countryman. So for a kinsman of another faith
# the faith fact is unsayable here. That is not an oversight: the creed gets its
# own clause class or it does not get said. Do not fold it into these five.
#
# THE FALLBACK IS AN EMPTY STRING, AND IT IS UNREACHABLE TODAY. Both halves
# matter. Unreachable because bc_write_bond_effect writes bc_battle_bond on every
# one of its six paths - five ladder arms and the leaderless `else` - with no
# leading remove_variable, and bc_ledger_effects.txt:141 calls it unconditionally
# from bc_battle_open_effect, which every one of the ten toast sites runs
# downstream of. Contrast the ground clause, whose fallback IS reachable. Empty
# because if a future path ever does leave the variable unwritten, any sentence
# about the foe would be presuming a foe that path could not name. Silence is the
# only honest output, and house style requires the arm to exist regardless.
